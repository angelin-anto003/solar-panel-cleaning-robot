# Autonomous Solar Panel Cleaning Robot with Fault Detection Using Computer Vision

## Project Overview

This project combines a solar panel cleaning robot with a computer-vision-based fault detection system.

## Objectives

- Develop a robot for solar panel cleaning.
- Implement robot movement and Bluetooth serial control using Arduino.
- Use ultrasonic sensing for distance measurement and obstacle-related logic.
- Explore computer vision for identifying solar panel faults.

## Hardware Components

- Arduino microcontroller
- L298N motor driver
- HC-SR04 ultrasonic sensor
- Servo motor
- HC-05 Bluetooth module
- Cleaning mechanism and robot chassis

## Software and Technologies

- Arduino C/C++
- Python
- OpenCV
- Streamlit
- Roboflow computer-vision API

## Repository Contents

- `arduino/` — robot controller source code
- `computer-vision/` — computer-vision application
- `docs/` — project documentation
