# Solar Panel Cleaning Robot with Computer Vision-Based Fault Detection

## Project Overview
This project aims to detect dirt and other visible surface issues on solar panels using computer vision and to support automated cleaning using a robot.

The project has two main components:

- **Computer Vision:** Image-based detection using Python, OpenCV, Roboflow, and Streamlit.
- **Cleaning Robot:** Arduino-based control with Bluetooth communication, a cleaning mechanism, and ultrasonic sensing for edge detection.

## Technologies
- Python
- OpenCV
- Roboflow
- Streamlit
- Arduino
- Bluetooth communication
- Ultrasonic sensor
